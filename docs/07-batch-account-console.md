# 批量成品号与 Web 控制台

## 1. 目标

这部分能力面向两个场景：

1. 批量生成一批标准规则账号，直接加入假人控制列表。
2. 批量导入已经准备好的成品号，在 `http://localhost:3000/home` 里做可视化控制。

---

## 2. 首页现在能做什么

新版首页控制台支持下面这些操作：

- 查看连接统计：`All Connect`、`AAA Connect`、`GS Connect`、`Lost Connect`
- 批量生成账号
- 批量导入成品号
- 批量登录选中账号
- 批量退出选中账号
- 批量执行成品准备
- 批量执行降妖
- 删除控制列表里的账号
- 对单个账号执行登录、退出、成品准备、降妖、删除

---

## 3. 批量生成账号

页面区域：`批量生成账号`

字段说明：

- `前缀`
  例如 `A`、`B`、`WD`
- `编号位数`
  例如 `4`，则生成 `0001`
- `起始编号`
  例如 `1`
- `生成数量`
  例如 `20`
- `角色名策略`
  - `cn_random`：随机中文名
  - `gender_pool`：男女名池
- `角色性别策略`
  - `account_parity`：按账号尾号决定男女
  - `random`：随机性别
  - `male`：固定男角
  - `female`：固定女角
- `生成后自动登录`
  勾选后会在生成完成后立刻触发登录

说明：

- 上面两项策略只会在账号首次建角色时生效。
- 已经存在角色的成品号不会被改名。

生成规则：

```text
110001 + 前缀 + 左补零编号
```

例如：

- 前缀 = `A`
- 位数 = `4`
- 起始编号 = `1`
- 数量 = `3`

会生成：

- `110001A0001`
- `110001A0002`
- `110001A0003`

---

## 4. 导入成品号

页面区域：`导入成品号`

支持输入格式：

- 每行一个账号
- 空格分隔
- 英文逗号分隔
- 中文逗号分隔
- 分号分隔

示例：

```text
110001A0001
110001A0002
110001wd0001
```

导入时会做两件事：

1. 自动去重
2. 如果账号不是以 `110001` 开头，会自动补上 `110001`

例如：

- 输入 `wd0001`
- 最终会归一化成 `110001wd0001`

---

## 5. 成品准备逻辑

页面里的“成品准备”会调用后端的 `prepareFinishedClient(account)`。

当前逻辑包括：

1. 领取宠物邮件：`mail_pet`
2. 领取角色邮件：`mail_name`
3. 领取装备邮件：`mail_equip`
4. 购买会员：`vip_type`
5. 设置参战宠物：`War_pet`
6. 设置推荐加点
7. 设置骑乘坐骑：`Ride_pet`
8. 自动装备飞行法宝：`equip_fly`

前提条件：

- 该账号已经连上 `GS`
- 对应邮件、宠物、坐骑、法宝名称已经在配置里填对

如果账号未连上 `GS`，页面触发后端时会返回失败结果，不会执行成品准备。

---

## 6. 数据落盘规则

账号控制列表持久化文件：

```text
data/list.json
```

现在这个文件只负责保存账号台账本身，不再在每次刷新页面时把临时连接状态写回去。

这样做的好处：

- 减少无意义文件改动
- 避免页面刷新把台账文件污染成运行时缓存
- 更适合后续维护和 Git 提交

## 7. 新增 HTTP API

### 7.1 批量生成账号

`POST /api/accounts/generate`

请求体：

```json
{
  "prefix": "A",
  "indexNum": 4,
  "startIndex": 1,
  "count": 20,
  "charNameMode": "cn_random",
  "charGenderMode": "account_parity",
  "autoLogin": true
}
```

### 7.2 导入成品号

`POST /api/accounts/import`

请求体：

```json
{
  "accountsText": "110001A0001 110001A0002",
  "startIndex": 1,
  "autoLogin": false
}
```

### 7.3 删除账号

`POST /api/accounts/delete`

请求体：

```json
{
  "accounts": ["110001A0001", "110001A0002"]
}
```

### 7.4 批量登录

`POST /api/accounts/login`

### 7.5 批量退出

`POST /api/accounts/logout`

### 7.6 成品准备

`POST /api/accounts/prepare-finished`

### 7.7 批量降妖

`POST /api/accounts/xiangyao`

## 8. 页面操作建议

推荐日常使用顺序：

1. 先在 `/config` 配好默认密码、邮件标题、宠物名、坐骑名、法宝名
2. 回到 `/home`
3. 批量导入成品号或批量生成账号
4. 先登录账号
5. 确认 `GS` 已连接
6. 再批量执行“成品准备”
7. 最后再批量执行降妖、组队等行为

---

## 9. 注意事项

1. “成品准备”不是离线任务，账号必须已经进入游戏侧。
2. 页面里看到的连接状态是实时计算结果，不是静态配置值。
3. `data/list.json` 只是控制台账号池，不等于当前内存里所有 `clients` 的绝对真相。
4. 如果后续要继续扩展页面，优先改：
   - `views/index.ejs`
   - `main.js`
   - `data/data.js`
