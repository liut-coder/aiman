# 多实例账号归属锁

## 1. 目标

这个机制用于解决一台服务器同时运行多个实例时，账号池被重复管理的问题。

典型风险：

1. 实例 A 导入了一批号，实例 B 又点了“全部登录”。
2. 两个实例同时对同一批假人执行“成品准备”或“降妖”。
3. 多个进程同时改写 `data/list.json`，导致账号台账互相覆盖。

现在项目改成“共享台账 + 实例归属 + 租约续租”模式，避免跨实例抢号。

## 2. 共享台账

账号池仍然落在：

```text
data/list.json
```

但它现在除了保存账号本身，还会保存归属信息。

每条记录可能包含：

- `ownerInstanceId`
- `ownerLabel`
- `ownerHost`
- `ownerPort`
- `ownerPid`
- `ownerLeaseMs`
- `ownerLeaseUntil`
- `ownerLastHeartbeatAt`

最关键的是：

- `ownerInstanceId`：当前账号属于哪个实例
- `ownerLeaseUntil`：归属何时过期

## 3. 文件互斥锁

为了防止多个 Node 进程同时改写账号池，所有写 `data/list.json` 的动作都会先抢：

```text
data/list.lock
```

这是一个短时文件锁，只保护“读 -> 改 -> 写”这一步，不代表账号长期归属。

账号长期归属靠的是 owner/lease，不是 `list.lock`。

## 4. 归属和租约规则

### 4.1 当前默认值

- `INSTANCE_LEASE_MS=120000`
- `INSTANCE_HEARTBEAT_MS=15000`

含义：

- 一个实例拿到账号后，锁默认持续 120 秒
- 实例每 15 秒自动续租一次
- 如果实例异常退出，不再续租，其他实例等租约过期后可接管

### 4.2 claim 规则

某个实例在操作账号前，会先尝试 claim：

1. 账号未归属：直接拿下
2. 账号已归属给当前实例：直接续租
3. 账号归属给其他实例，但租约已过期：允许接管
4. 账号归属给其他实例，且租约仍有效：拒绝接管

## 5. 哪些操作会走归属锁

以下流程已经接到实例归属锁：

- 批量生成账号
- 批量导入账号
- 全部登录
- 单账号登录
- 批量登录
- 批量退出
- 成品准备
- 降妖
- 删除账号

也就是说，别的实例正在持有的账号，不会再被本实例重复接管。

## 6. 首页表现

`/home` 的账号列现在会显示归属状态：

- `当前实例`
- `已锁定 hostname:port`
- `锁已过期 hostname:port`

如果账号正被其他实例持有，单账号按钮会直接禁用。

批量操作仍然允许勾选整表，但后端会跳过冲突账号，并返回提示信息。

## 7. 实例标识

当前实例标识基于以下信息生成：

- 主机名
- HTTP 端口
- 项目根目录

因此同一台服务器上：

- 不同 `HTTP_PORT` 会被识别为不同实例
- 同一个端口重启后仍会保持同一个实例身份

这对“实例重启后继续接管自己之前的账号”很重要。

## 8. 退出与接管

### 8.1 正常退出

如果通过页面退出或进程收到 `SIGINT` / `SIGTERM`，实例会主动释放自己持有的账号归属。

### 8.2 异常退出

如果实例崩掉，没有机会主动释放，也不用手动清锁：

1. 等租约过期
2. 由其他实例重新 claim

## 9. 使用建议

1. 多开时给每个实例配置不同的 `HTTP_PORT`
2. 让某个实例先导入或先登录它要管理的账号，明确归属
3. 不要指望多个实例共同管理同一批号，这一版的设计就是“单账号单实例”
4. 如果你看到“已锁定其他实例”，说明后端保护已经生效

## 10. 可调参数

可通过环境变量调整：

```bash
HTTP_PORT=3001
INSTANCE_LEASE_MS=180000
INSTANCE_HEARTBEAT_MS=20000
```

建议：

- `INSTANCE_HEARTBEAT_MS` 明显小于 `INSTANCE_LEASE_MS`
- 不要把租约时间调得过短，否则瞬时抖动时容易误判过期

## 11. 手动开关

现在还支持一个运行时配置开关：

- `instance_lock_enabled`

含义：

- `1`：开启实例归属锁
- `0`：关闭实例归属锁

关闭后：

1. 当前实例会忽略 owner / lease 拦截
2. 当前实例会停止续租
3. 当前实例会主动释放自己持有的账号归属

这个开关适合单实例临时调试，或者你明确不想让账号池做多实例隔离的时候使用。
